# وائم WAEM 360° — MVP Foundation 0.1.0

نسخة تأسيسية للمرحلة الأولى وفق وثيقة المتطلبات المرفقة. تتضمن واجهة عربية RTL، لوحة قيادة أولية، شاشة مستخدمين تجريبية، ومخطط قاعدة بيانات PostgreSQL قابلًا للتوسع.

## ما يتضمنه الإصدار

- Next.js App Router + React + TypeScript.
- واجهة عربية RTL متجاوبة.
- لوحة قيادة تعرض المهام الثماني المحددة في وثيقة المتطلبات، مع توضيح أن المؤشرات غير المالية غير متاحة قبل إدخال البيانات.
- شاشة إدارة مستخدمين تجريبية تدعم الإضافة والبحث والحفظ المحلي في المتصفح.
- مخطط Prisma يشمل المؤسسة والفروع والمستخدمين والأدوار والصلاحيات والمشاريع والمهام وسجل التدقيق.
- Seed أولي للأدوار والصلاحيات والمؤسسة التجريبية والمشروع.
- نقطة فحص `GET /api/health`.

## التشغيل المحلي

المتطلبات: Node.js 20.9+ وPostgreSQL.

```bash
cp .env.example .env
# عدّل DATABASE_URL في .env
npm install
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

ثم افتح `http://localhost:3000`.

## ملاحظات مهمة قبل الإنتاج

1. شاشة المستخدمين الحالية نموذج واجهة فقط؛ التخزين في Local Storage ولا توجد مصادقة أو حماية API فعلية.
2. يجب دمج مزود مصادقة موثوق، وتطبيق فحص RBAC على الخادم وكل واجهات API قبل إدخال مستخدمين حقيقيين.
3. يلزم إعداد سجل تدقيق غير قابل للتلاعب، وإدارة أسرار، وسياسة نسخ احتياطي، ومراجعة أمنية.
4. لم يتم تنفيذ تكامل ZATCA أو الفوترة الإلكترونية أو أي تكامل حكومي.
5. لا توجد بيانات مالية فعلية أو نتائج إنجاز؛ القيم التجريبية موسومة في الواجهة.
6. مخطط قاعدة البيانات نقطة انطلاق؛ يحتاج مراجعة هندسية قبل اعتماده للإنتاج.
