# وائم WAEM 360° — نسخة مستقلة لـ GitHub Pages

هذه نسخة **تعمل مباشرة** على GitHub Pages دون Node.js، أو Next.js، أو قواعد بيانات، أو Prisma، أو Express، أو خوادم API، أو مكتبات JavaScript أو خطوط أو خدمات CDN خارجية.

## النشر على حسابك الحالي

رابط المستودع: https://github.com/shjnteam/waem

1. افتحي مستودع `shjnteam/waem`.
2. احذفي ملفات النسخة السابقة من المستودع (أو ارفعي ملفات هذه النسخة إلى الجذر مع حذف القديمة).
3. ارفعي **محتويات** هذا الملف المضغوط إلى الجذر: `index.html`, `app.js`, `styles.css`, `.nojekyll`, `README.md`.
4. افتحي **Settings → Pages**.
5. في **Build and deployment** اختاري **Deploy from a branch**، ثم `main` و`/(root)` واحفظي.
6. افتحي https://shjnteam.github.io/waem/ بعد إتمام نشر GitHub Pages.

> هام: إن كان إعداد Pages السابق يستخدم **GitHub Actions**، غيّريه إلى **Deploy from a branch**. لا تحتاج هذه النسخة إلى Actions أو npm.

## الميزات

- لوحة قيادة ديناميكية مبنية على البيانات المسجلة.
- إدارة المهام الثماني الأصلية وإضافة المهام وتعديل حالتها وحذفها.
- إدارة المستخدمين والأدوار **كتسميات محلية فقط**، دون تسجيل دخول أو صلاحيات حقيقية.
- إضافة العملاء والباقات والاشتراكات والفواتير والمدفوعات اليدوية.
- حفظ تلقائي في `localStorage`، وتصدير واستيراد ملف JSON، وسجل نشاط محلي.
- تصميم عربي RTL متجاوب، دون طلب ملفات أو خطوط أو بيانات من أي موقع خارجي.

## التشغيل دون أي تثبيت

افتحي ملف `index.html` بالنقر المزدوج مباشرة في المتصفح. لا تحتاجين إلى خادم أو اتصال إنترنت بعد تنزيل الملفات.

## حدود النسخة

- البيانات **محلية لكل متصفح/جهاز**، ولا تتزامن بين الأجهزة.
- حذف بيانات المتصفح قد يمحوها؛ استخدمي صفحة النسخ الاحتياطي لتصديرها.
- لا يوجد نظام دخول، أو حماية معلومات حقيقية، أو بوابة دفع، أو إرسال بريد، أو اتصال بنكي، أو فواتير ZATCA معتمدة.
- هذه أداة عرض وإدارة محلية أولية وليست نظامًا إنتاجيًا لحفظ بيانات مالية أو شخصية حساسة.
- GitHub هو مكان استضافة ملفات الموقع فقط، وليس قاعدة بياناته.
